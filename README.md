
# 점심 조 3명·4명 편성 변경 패치

`meal_groups_3_or_4_patch.sql` 파일을 Supabase의 SQL Editor에서 실행하세요.

## 변경된 편성 방식

- 3명 → 3명 1조
- 4명 → 4명 1조
- 6명 → 3명 + 3명
- 7명 → 4명 + 3명
- 8명 → 4명 + 4명
- 9명 → 3명 + 3명 + 3명
- 10명 → 4명 + 3명 + 3명
- 11명 → 4명 + 4명 + 3명
- 12명 → 4명 + 4명 + 4명

20층 선택자가 1명, 2명 또는 5명인 날은 3명·4명 조만으로 전원을 편성할 수 없어 자동 조를 생성하지 않습니다.
