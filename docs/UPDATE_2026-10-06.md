# 2026-10-06 관리자 및 학생 기능 변경

## 적용 순서

1. Supabase SQL Editor에서 `class_management_update.sql` 전체를 실행합니다. 필요한 테이블, 조 생성 함수, 신청·취소 함수, 자리 공개 규칙이 함께 반영됩니다. 기존 신청·자리표·조 기록은 삭제하지 않습니다.
2. 같은 SQL Editor에서 `class_management_cron.sql`을 실행합니다. Supabase Cron이 마감 여부를 매분 확인해 평일에 하루 한 번 자동 편성합니다. 마감 시간을 변경해도 스케줄을 다시 수정할 필요가 없습니다.
3. 변경된 파일을 Git에 반영하고 Vercel에 재배포합니다. SQL 적용 전 새 화면을 배포하면 새 API가 사용할 테이블·함수가 없어 오류가 발생합니다.

Supabase Cron 설치 안내: https://supabase.com/docs/guides/cron/install

## 학생 밥친구 화면

- 화면 최상단에 오늘 밥친구 조와 멤버를 표시합니다. 층별 카드가 다른 층의 높이에 맞춰 늘어나지 않습니다.
- 신청은 10층 또는 20층 중 선택합니다. `혼자 먹기` 선택지는 제거했습니다. 과거에 0으로 저장한 값은 미신청으로 취급하고 새 신청은 10·20만 받습니다.
- 마감 전에 `신청 취소`를 누르면 해당 학생의 오늘 신청만 삭제됩니다. 미신청 학생은 조에 포함되지 않습니다. 마감 시간에는 신청·변경·취소가 모두 차단되며 서버와 DB에서도 검사합니다.
- 마감 전에 이미 조가 편성되어 있으면 신청 변경·취소와 조 갱신을 한 트랜잭션으로 처리합니다. 취소한 사람이 기존 조에 남지 않습니다. 5명 중 1명이 취소하면 남은 4명이 4명 조로 재편성됩니다. 남은 사람이 1명 또는 2명이면 해당 층의 조가 생성되지 않습니다.
- 신청 현황에는 10층·20층·미신청 인원 수만 표시합니다. 신청자 명단은 학생 API 응답에서 제외하고 직접 DB 조회 권한도 제거합니다. 편성 완료된 조의 멤버 이름은 표시합니다.

## 관리자 밥친구 화면

- `점심 관리`와 독립된 `밥친구 관리` 탭에서 날짜별 신청 명단, 미신청자 할당, 조 편성을 관리합니다.
- 마감 시간을 시·분 단위로 저장합니다. 기본은 한국 시간 12:00이며, 변경은 오늘 신청과 취소에도 적용됩니다.
- 마감 시간이 바뀌면 그날 자동 편성 기록을 갱신하여 새 마감 이후 편성할 수 있습니다. 같은 마감 시간으로 반복 저장하는 것은 기존 자동 편성을 재실행하지 않습니다.
- 기존 Vercel의 낮 12시 Cron은 마감 전에는 건너뛰고 자동 편성 완료 후에는 중복 실행하지 않는 보조 실행으로 유지합니다. 실제 변경 가능한 자동 편성은 Supabase Cron이 담당합니다. 자동 편성 이후 관리자의 수동 재편성도 가능합니다.
- 업데이트 전에 오늘 조가 이미 편성되어 있으면 초기 Cron이 다시 추첨하지 않고 유지합니다. 이후 신청 변경·취소나 마감 시간 변경에는 새 상태를 반영합니다.

## 자리 관리와 신고

- 좌석은 1~30번입니다. 복구한 1번은 첫 줄에서 2번 왼쪽에 표시됩니다.
- 학생과 사용 가능한 좌석을 각각 Fisher–Yates 방식으로 섞습니다. 좌석이 남으면 어느 좌석이 비는지도 무작위이며 특정 방향에 빈자리를 우선 배치하지 않습니다. 과거 반복을 피하는 점수 최적화는 제거했습니다.
- 관리자 → 자리 배치 → 좌석 상태에서 사용 불가 여부와 사유를 저장합니다. 모든 관리자와 학생 화면에 공유되며 사용 불가 좌석은 추첨과 직접 배치·저장에서 제외됩니다. 사유를 적고 `저장`해야 적용됩니다. 이전 브라우저에만 저장된 배정 제외 좌석은 이 화면에서 사유와 함께 다시 등록합니다.
- 이미 저장된 자리표의 좌석이 나중에 사용 불가로 바뀌면 해당 이름과 사용 불가 사유를 함께 표시합니다. 관리자에게 새로운 자리표를 등록할 때 배치 수정이 필요함을 알립니다.
- 학생 → 자리표 → 자리 오류 신고에서 자리 번호, 신고자 이름, 사유를 보냅니다. 등록된 활성 학생 이름을 확인하고, 관리자는 접수 내용·신고자·날짜를 확인하고 처리 완료로 변경합니다. 신고자의 이름과 사유는 학생 API로 공개하지 않습니다.
- 자리 적용일의 7일 전 한국 시간 00시부터 자리표가 공개되고, 다음 자리표 공개일까지 표시됩니다.
