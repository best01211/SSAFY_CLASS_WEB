
# 빈자리 오른쪽 우선 배치 업데이트

## 적용 규칙

활성 학생이 27명이면:

```text
30번 빈자리
```

활성 학생이 26명이면:

```text
29번, 30번 빈자리
```

활성 학생이 25명이면:

```text
28번, 29번, 30번 빈자리
```

이후에도 오른쪽 뒤쪽부터 다음 순서로 비웁니다.

```text
30 → 29 → 28 → 25 → 24 → 23
→ 20 → 19 → 18 → 15 → 14 → 13
→ 10 → 9 → 8 → 5 → 4 → 3
```

오른쪽 자리를 모두 비워야 할 정도로 학생 수가 줄어든 경우에만 왼쪽 자리도 비웁니다.

자리 생성 시 상태창에 실제 빈자리 번호가 표시됩니다.

## 적용 방법

기존 프로젝트에 전체 덮어쓰거나 `admin.html`만 덮어쓰세요.

```bash
git add admin.html
git commit -m "Prefer right-side empty seats"
git push
```

Vercel 배포 후 `Ctrl + F5`로 새로고침하세요.
