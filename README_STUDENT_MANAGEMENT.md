
# 학생 관리·기본 20층·자리 예약 관리 업데이트

## 추가 기능

### 학생 관리
관리자 화면에 `학생 관리` 탭이 추가됩니다.

- 학생 추가
- 이름 수정
- 메모 수정
- 활성/비활성 전환
- 학생 삭제
- 활성 학생 수 확인

자리 생성과 점심 조 생성은 활성 학생만 대상으로 합니다.

### 기본 20층 배정
모든 활성 학생은 별도 입력이 없어도 당일 20층으로 간주합니다.

- 아무 선택도 하지 않음 → 20층
- 20층 선택 → 20층
- 10층 선택 → 20층 조에서 제외

관리자 점심 현황에서는 자동 20층 학생에게 `(자동)`이 표시됩니다.

### 자리 예약 관리
예약 목록에 다음 버튼이 추가됩니다.

- 보기: 예약 자리표 미리보기
- 삭제: Supabase 예약 삭제

### Welplan 메뉴 사진
Welplan API 응답에 이미지 URL이 있으면 메뉴 카드에 사진을 표시합니다.
API가 이미지 URL을 제공하지 않는 메뉴는 `사진 없음`으로 표시됩니다.

## 적용 순서

1. 현재 프로젝트에 전체 덮어쓰기
2. Supabase SQL Editor에서 실행:

```text
student_management_upgrade.sql
```

3. Git 반영:

```bash
git add .
git commit -m "Add student management and default 20F assignment"
git push
```

4. Vercel 자동 배포 완료 후 `Ctrl + F5`

## 주의

활성 학생은 사용 좌석 28명을 넘을 수 없습니다.
비활성 학생은 과거 기록은 유지되지만 새 자리와 새 점심 조에서 제외됩니다.
